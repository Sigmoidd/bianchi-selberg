# Finite quotients and adjacency operators

`quotients/` depends only on the exact field, ideal and matrix modules.
Importing it does not import Arb, the trace engine, group inventory proofs
or numerical libraries. The exact data formerly embedded in
`fields/quadratic.py` now live in `fields/arithmetic.py`; the old module
re-exports them. Lazy `groups` exports preserve existing caller imports.

The boundary is explicit:

| Layer | Input | Output / responsibility |
|---|---|---|
| `ResidueRing` | `LevelIdeal(d, hnf)` | Canonical O/I representatives and exact ring operations |
| `ProjectiveMatrices` | Residue ring | Determinant-one matrices modulo the global signs ±I |
| `generated_action` | Ideal and integral matrix generators | Complete generated image, vertices and right multiplication permutations |
| `FiniteAction` | Enumerated action | Integer adjacency or rational normalized transition products |
| Future spectral module | Action/permutations | Eigenvalue or Cheeger certificates, with their own proof gates |
| Existing trace backend | Group/inventory/cusp data | Level-one Laplace certificate |

For HNF basis (a,0),(b,c), reduction sends (x,y) to
((x−b floor(y/c)) mod a, y mod c). Over composite rings, the projective
convention identifies only M and −M; it does not identify all extra scalar
solutions to u²=1. This matches the specified global PSL lifts.

Breadth-first closure returns the **entire subgroup generated by the listed
images**, not a surjectivity claim about an ambient finite group. A size cap
raises an error and returns no partial action. Default lifts are S, T₁, T_g,
and symmetrization appends their inverses. The generator list is a multiset:
repeated images and identity loops retain their multiplicities. Consequently
A·1=degree·1, and the normalized operator is A/degree. The permutation for
g takes index v to v g, so `(A f)[v]=Σ_g f[v g]`. A symmetric multiset
gives a symmetric adjacency operator. The JSON preserves this convention,
all generator images and every permutation for independent replay.

```python
from groups.identity import LevelIdeal
from quotients import generated_action

P = LevelIdeal.principal(7, (0, 1))     # (τ), norm 2
Q = LevelIdeal.principal(7, (1, -1))    # (1−τ), the other norm-2 prime
A = generated_action(P)               # order 6, degree 6
B = generated_action(LevelIdeal.rational(7, 3))  # order 360, degree 6
assert A.symmetric and B.symmetric
assert A.adjacency_product([1]*A.order) == (6,)*A.order
```

These two norm-2 images have different reductions of τ (0 and 1).
The mod-3 image has residue field of size 9 and order 360, agreeing
with |PSL₂(F₉)|. The tests check generated orders, full permutations,
symmetry including multiplicities, signs, composite ideals and size-cap
failure. Enumeration itself proves the generated image sizes; no group
order formula is needed to trust the result.

```sh
python examples/finite_quotient.py 7 --level-generator 3 0 --output /tmp/d7-mod3.json
```

An eigenvalue module can consume the permutations without modifying ring
arithmetic or trace assembly; exact characteristic polynomials or interval
eigenvalue bounds can be added there. A Cheeger module can consume the
same multiset edges and certify cuts with that loop/multiplicity convention.
Neither an explicit eigenvalue bound nor a Cheeger constant is claimed yet.
Nor does the level-one B<1 certificate imply a uniform gap for congruence
covers: that requires its own automorphic or finite-graph argument.
